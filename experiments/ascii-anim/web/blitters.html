Four Ways To Draw A Circle

The same expanding ring, blitted four ways. Our effects use one glyph per cell; a terminal can carry 2, 4 or 8 subpixels in the same cell instead, which is how every serious terminal graphics library draws a curve. The catch is the house rule: only the half blocks are in CP437, so the higher modes buy resolution by leaving the cmd alphabet behind. Font support is measured live below, not assumed.

Reading

  • Take the data, not the dependency. Nothing here needs to be linked. The parts worth having are a JSON file of frame sequences, a dozen lines of heat propagation, a character ramp and a file format — all small enough to carry as our own code, which also keeps the licence question simple.
  • Resolution is a house-rule decision, not a technical one. Quadrants and braille work and the font has them; they just stop looking like a console. Half blocks are the only upgrade that stays inside CP437.
  • The layer system makes REXPaint interesting. Its .xp format is layered per cell with a character and two colours, which is the shape our buffer already has — hand-drawn panels and title art could load straight in.
